# Перший плагін крок за кроком

На цій сторінці ви напишете маленький, але справжній плагін: вид змагань «Заданий напрямок з форою за віком».
Усе як у звичайному заданому напрямку, тільки учасникам від 50 років час зменшується на 5 %, і місця
розставляються вже за скоригованим часом. Так роблять на сімейних і корпоративних стартах, де всі біжать одну
дистанцію. Далі ви винесете вік і відсоток у налаштування й додасте колонку «Фора».

## Що знадобиться

- [.NET 10 SDK](https://dotnet.microsoft.com/download) — перевірте командою `dotnet --version` (має бути 10.x);
- [git](https://git-scm.com/);
- будь-який редактор C#: Visual Studio, JetBrains Rider або VS Code з розширенням C# Dev Kit;
- встановлена програма OrientPyx — щоб перевірити плагін (або запуск програми з вихідного коду, див.
  [Налагодження](debugging.md#run-from-source)).

Працює на Windows, macOS і Linux.

## Крок 1. Клонуйте репозиторій

SDK плагінів — частина репозиторію програми, тож плагін пишуть поруч зі стандартними:

```bash
git clone https://github.com/VadymKolesnyk/OrientPyx.git
cd OrientPyx
```

!!! tip "Збирайте проти тієї версії, що стоїть у користувачів"
    Гілка `main` може містити нові типи SDK, яких ще немає у випущеній програмі. Якщо плагін призначений для
    конкретної версії, перейдіть на її тег, наприклад `git checkout v0.7.16`
    (версію видно в «Довідка → Про програму»). Детальніше — у [Поширення і версії](sharing.md#versions).

## Крок 2. Створіть проєкт

Створіть папку `plugins/AgeHandicap` і в ній файл `AgeHandicap.csproj` з одного рядка:

```xml
<Project Sdk="Microsoft.NET.Sdk" />
```

Решту дає спільний файл `plugins/Directory.Build.props`, який MSBuild підхоплює для кожного проєкту в `plugins/`:

- `net10.0`, `Nullable` і `ImplicitUsings` увімкнено;
- `EnableDynamicLoading` — збірка придатна для завантаження як плагін;
- посилання на проєкт `src/OrientPyx.Plugins.Sdk` з `Private="false"` і `ExcludeAssets="runtime"`: ви
  компілюєтеся проти SDK, але сама бібліотека SDK у вихідну папку **не копіюється** — під час роботи її дає
  програма;
- вихідна папка — `artifacts/plugins/<НазваПроєкту>/` у корені репозиторію (для Debug і Release однаково).

!!! note "Назва проєкту = назва папки = назва DLL"
    Програма шукає плагін саме як `<папка плагінів>/<Назва>/<Назва>.dll`, а збирання кладе DLL у папку з назвою
    проєкту. Тому назвіть папку й файл проєкту однаково (тут `AgeHandicap`) і не змінюйте `AssemblyName`.

Додайте проєкт до рішення плагінів, щоб він збирався разом зі стандартними:

```bash
dotnet sln plugins/OrientPyx.Plugins.sln add --in-root plugins/AgeHandicap/AgeHandicap.csproj
```

## Крок 3. Напишіть плагін

Створіть файл `plugins/AgeHandicap/AgeHandicapPlugin.cs`:

```csharp
using OrientPyx.Plugins.Sdk;
using OrientPyx.Plugins.Sdk.Toolkit;

namespace AgeHandicap;

/// <summary>Точка входу: програма знаходить цей клас, читає Info і один раз викликає Register.</summary>
public sealed class AgeHandicapPlugin : IOrientPyxPlugin
{
    public PluginInfo Info => new("handicap", "Фора за віком", "1.0",
        Author: "Ваше ім'я", Description: "Старшим учасникам час зменшується на кілька відсотків.");

    public void Register(IPluginBuilder p)
    {
        p.AddDiscipline<HandicapSetCourse>();
        p.AddStrings("uk-UA", new Dictionary<string, string>
        {
            ["name"] = "Заданий напрямок з форою за віком",
        });
        p.AddStrings("en-US", new Dictionary<string, string>
        {
            ["name"] = "Set course with age handicap",
        });
    }
}

/// <summary>Вид змагань: усе як у заданому напрямку, крім часу.</summary>
public sealed class HandicapSetCourse : Discipline
{
    public override string Id => "handicap.set-course";

    public override string Name => "name";

    public override BuiltinDiscipline BasedOn => BuiltinDiscipline.SetCourse;

    public override TimeSpan AdjustTime(AdjustContext ctx)
    {
        // Рік народження невідомий або учасникові менше 50 — час без змін.
        if (ctx.Participant.BirthYear is not { } year || Age.InYear(year, ctx.Date) < 50)
            return ctx.Time;

        return ctx.Time * 0.95;   // фора 5 %
    }
}
```

Що тут відбувається:

- **`Info`** — паспорт плагіна. Перший параметр, `"handicap"`, — ідентифікатор плагіна: його не можна змінювати
  після того, як плагін почали використовувати. Назву, версію, автора й опис видно на сторінці «Плагіни».
- **`Register`** — тут плагін повідомляє, що він додає: один вид змагань і написи двома мовами.
- **`Id`** виду змагань — `"<ідентифікатор плагіна>.<назва>"`. Цей рядок зберігається в змаганні, тож він теж
  назавжди.
- **`Name`** — ключ напису `"name"`; програма шукає його серед рядків плагіна поточною мовою.
- **`BasedOn`** — основа. Усе, що ви не перевизначили, працює як у «Заданому напрямку»: перевірка відміток,
  спліти, старт, місця.
- **`AdjustTime`** — єдине змінене правило. Програма викликає його для кожного результату зі статусом OK і
  ставить місця за тим, що він поверне. Змінений час програма округлює до цілої секунди.
- **`Age.InYear`** — вік так, як його рахують в орієнтуванні: рік дня змагань мінус рік народження.

!!! warning "Не змінюйте `Id` після першого використання"
    Змагання пам'ятають вид змагань за `Id`. Якщо його змінити, у вже створених змаганнях цей день
    показуватиме банер «Потрібен плагін», а результати рахуватимуться без місць.

## Крок 4. Зберіть

```bash
dotnet build plugins/OrientPyx.Plugins.sln -c Release
```

Збереться SDK, обидва стандартні плагіни і ваш. Ваш плагін з'явиться в `artifacts/plugins/AgeHandicap/`:

```
artifacts/plugins/AgeHandicap/
  AgeHandicap.dll
  AgeHandicap.deps.json
  AgeHandicap.pdb
  AgeHandicap.runtimeconfig.json
```

Файлу `OrientPyx.Plugins.Sdk.dll` там немає — так і має бути.

## Крок 5. Покладіть плагін у папку плагінів

1. Відкрийте в OrientPyx будь-яке змагання — меню «Плагіни» доступне лише з відкритим змаганням. Для проби
   підійде демо [demo-kubok](../demo/demo-kubok.opyx): двічі клацніть завантажений файл і натисніть «Ок» (запасний
   варіант — «Файл → Імпорт змагань…»).
2. Відкрийте «Плагіни → Керування плагінами…» і натисніть «Відкрити папку плагінів» — відкриється папка у
   файловому менеджері.
3. Закрийте OrientPyx.
4. Скопіюйте туди **всю папку** `artifacts/plugins/AgeHandicap`, щоб вийшло `…/plugins/AgeHandicap/AgeHandicap.dll`.
5. Запустіть OrientPyx знову: нові й оновлені плагіни читаються лише під час запуску.

Папка плагінів лежить поза папкою програми, тож оновлення OrientPyx її не чіпають. Зазвичай це
`%LocalAppData%\OrientPyx-data\plugins` на Windows і `~/Library/Application Support/OrientPyx/data-root/plugins`
на macOS, але надійніше відкривати її кнопкою.

!!! tip "Під час розробки копіювати не треба"
    Якщо запускати програму з вихідного коду в конфігурації Debug, вона сама копіює все з `artifacts/plugins`
    у свою папку плагінів під час кожного запуску. Зібрали — перезапустили — перевіряєте. Див.
    [Налагодження](debugging.md#run-from-source).

## Крок 6. Увімкніть плагін

Знайдений плагін вимкнений, доки ви його не ввімкнете. На сторінці «Плагіни → Керування плагінами…» позначте
«Увімкнено» біля «Фора за віком».

![Сторінка «Плагіни»](../shots/plugins.png){ .shot }

На знімку — два стандартні плагіни: у кожного назва, версія й автор, опис, папка, з якої його завантажено,
перемикач «Увімкнено» і (для ввімкненого) кнопка «Налаштування». Ваш плагін з'явиться в цьому ж списку. Якщо
замість нього рядок «Не завантажено: …» — див. [Налагодження](debugging.md#load-errors).

Вмикання діє одразу, без перезапуску, і для всіх змагань на цьому комп'ютері.

## Крок 7. Виберіть вид змагань

1. Відкрийте «Змагання → Дні».
2. У колонці «Вид змагань» потрібного дня виберіть «Заданий напрямок з форою за віком (плагін)» — позначка
   «(плагін)» додається до всіх видів змагань із плагінів.
3. Натисніть «Зберегти» в колонці «Дії» цього рядка.

Щоб фора діяла лише для однієї групи, а не для всього дня, виберіть вид змагань у колонці «Вид змагань» на
сторінці «Змагання → Групи».

## Крок 8. Перевірте результат

Відкрийте «Учасники» і виберіть день у списку днів угорі сторінки, або «Результати → Протоколи результатів». У
групі зі старшими учасниками їхній «Результат» став на 5 % меншим, і місця розставлено вже за ним. Очки за
формулою теж рахуються від скоригованого часу, а розряди — від фактичного.

Якщо нічого не змінилося, перевірте, що в учасника заповнено дату народження і що йому в рік змагань
виповнюється 50 або більше.

## Крок 9. Налаштування і власна колонка

Число 50 і 5 % зашиті в код. Винесіть їх у налаштування, щоб організатор міг змінити їх без нового плагіна, а
величину фори покажіть окремою колонкою. Замініть клас `HandicapSetCourse`:

```csharp
public sealed class HandicapSetCourse : Discipline
{
    public override string Id => "handicap.set-course";

    public override string Name => "name";

    public override BuiltinDiscipline BasedOn => BuiltinDiscipline.SetCourse;

    public override IEnumerable<SettingDef> Settings =>
    [
        Setting.Int("fromAge", "setting.fromAge", defaultValue: 50, min: 0, max: 100),
        Setting.Decimal("percent", "setting.percent", defaultValue: 5m, min: 0m, max: 50m),
    ];

    public override IEnumerable<ResultColumnDef> Columns =>
    [
        Column.Time("bonus", "column.bonus", r => r.Get<TimeSpan?>("bonus")),
    ];

    public override TimeSpan AdjustTime(AdjustContext ctx)
    {
        if (ctx.Participant.BirthYear is not { } year
            || Age.InYear(year, ctx.Date) < ctx.Setting<int>("fromAge"))
            return ctx.Time;

        var factor = 1 - (double)ctx.Setting<decimal>("percent") / 100;
        // Округлюємо самі, щоб «Фора» в колонці точно дорівнювала різниці часу.
        var adjusted = TimeSpan.FromSeconds(Math.Round(ctx.Time.TotalSeconds * factor, MidpointRounding.AwayFromZero));
        ctx.Row.Set("bonus", ctx.Time - adjusted);
        return adjusted;
    }
}
```

і додайте написи для нових ключів у `Register`:

```csharp
p.AddStrings("uk-UA", new Dictionary<string, string>
{
    ["name"] = "Заданий напрямок з форою за віком",
    ["setting.fromAge"] = "Фора з віку, років",
    ["setting.percent"] = "Фора, %",
    ["column.bonus"] = "Фора",
});
```

(так само для `"en-US"`).

Що нового:

- **`Settings`** — два налаштування. За замовчуванням значення окреме для кожного дня; щоб одне значення діяло
  на все змагання, передайте `scope: SettingScope.Competition`. Правило читає значення через
  `ctx.Setting<T>(ключ)`; поки організатор нічого не зберіг — діє значення за замовчуванням.
- **`Columns`** — колонка «Фора». Значення в неї кладе `ctx.Row.Set("bonus", …)`, а лямбда колонки читає його
  через `r.Get<TimeSpan?>("bonus")`. Учасникам без фори значення не задано — клітинка порожня.

Зберіть і перезапустіть програму. Відкрийте «Плагіни → Фора за віком» — сторінку вашого плагіна (туди ж веде
кнопка «Налаштування» на сторінці «Керування плагінами…»). Пункт меню з'явився ще тоді, коли ви ввімкнули
плагін, але досі сторінка казала «Цей плагін не має налаштувань.». Тепер на ній форма, яку програма будує сама,
по одній картці на кожен вид змагань плагіна з налаштуваннями, — так само, як у стандартного «Штраф замість
зняття»:

![Сторінка налаштувань плагіна](../shots/plugin-settings.png){ .shot }

На знімку — по картці на кожен вид змагань плагіна, цілі числа з кнопками «−» і «+», а вгорі вибір дня й кнопка
«Зберегти». Налаштування без позначки «для всього змагання» зберігаються для дня, вибраного вгорі. Напис «У
вибраному дні ця дисципліна не використовується» лише попереджає, що в цьому дні вид змагань ніде не вибрано, —
значення все одно можна змінити. Після «Зберегти» результати одразу перераховуються.

Колонка «Фора» з'явиться сама в таблиці дня на сторінці «Учасники» і в протоколі результатів (там її можна
сховати чи пересунути, як будь-яку іншу); для монітора її можна вибрати серед колонок.
