# Перевірка готовності дня

Перед стартом зручно переглянути все, що в даних дня ще не так: учасника без групи, групу без дистанції, однаковий
чіп у двох людей. Більшість таких проблем видно червоними й бурштиновими клітинками на різних сторінках —
«Старт → Перевірка готовності дня» збирає їх в один список, і з кожного рядка можна одразу перейти туди, де це
виправляють.

![Сторінка «Перевірка готовності дня»](../shots/day-readiness.png){ .shot }

Над таблицею — підсумок «Помилок: X · Попереджень: Y» або «Проблем не знайдено — дані дня готові.».

## Як користуватися

1. Відкрийте «Старт → Перевірка готовності дня» або натисніть плитку «Проблеми дня» на [Панелі](../start/overview.md#dashboard).
2. Якщо днів кілька, виберіть день угорі сторінки.
3. У рядку проблеми натисніть «Перейти» (або виділіть рядок і натисніть ++f8++). Відкриється сторінка з колонки
   «Де виправити», а на ній буде виділено потрібний рядок і клітинку. Якщо рядок ховав фільтр чи пошук у таблиці,
   вони скидаються.
4. Виправте проблему й поверніться на «Перевірку готовності дня» — список перечитується щоразу, коли сторінку
   відкривають. Зміни з інших комп'ютерів ([спільна робота](../race-day/network.md)) з'являються самі.

| Колонка | Що показує |
|---|---|
| «Рівень» | «Помилка» (червона) — результат буде хибним або його не буде; «Попередження» (бурштинове) — варто перевірити, але буває й нормою. Помилки йдуть першими. |
| «Перейти» | Відкрити сторінку, де це виправляють, на цьому рядку. |
| «Номер», «Що / хто» | Номер і ім'я учасника, назва групи (для варіанта дистанції — «Ч21 · A»), команда; для дня — «День N». |
| «Група» | Група учасника чи команди. |
| «Проблема» | Що не так і як виправити. Повний текст — у підказці при наведенні. |
| «Де виправити» | Сторінка, яку відкриє «Перейти». |

## Що перевіряється

| Перевірка | Рівень | Де виправити |
|---|---|---|
| Учасник дня без групи: групу не задано або її немає серед груп дня | помилка | «Учасники», «Група» |
| Немає чіпа | попередження | «Учасники», «Чіп» |
| Однаковий чіп у кількох учасників дня (зчитку отримає лише один) | помилка | «Учасники», «Чіп» |
| Чіп замалий для дистанції (лише коли [«Тип відмітки»](chips.md#readout-type) — SportIdent) | попередження | «Учасники», «Чіп» |
| Рік народження поза віковими межами групи | попередження | «Учасники», «Дата нар.» |
| Порожнє поле, якого вимагає вид змагань групи (плагін) | помилка | «Учасники», колонка поля |
| Значення додаткового поля, якого немає серед варіантів, або не число | попередження | «Учасники», колонка поля |
| Однаковий номер у кількох учасників дня | попередження | «Учасники», «Номер» |
| Немає часу старту | попередження | «Учасники», «Час старту»; «Старт → Жеребкування» |
| Естафета: у першого етапу немає ні часу старту, ні масового старту | попередження | «Старт → Масовий старт» |
| Група без дистанції | помилка | «Групи», «Порядок / список КП» |
| У дистанції код, якого немає серед КП дня (наприклад, S1 чи F без КП старту/фінішу) — уся група отримала б MP | помилка | «Групи» |
| Помилка в шаблоні змішаної дистанції або варіанта | помилка | «Групи» |
| Естафета «своя на кожен етап»: етап без жодної дистанції | помилка | «Групи» |
| Невідомий вид змагань дня чи групи (потрібен плагін, який не встановлено або вимкнено) | помилка | «Змагання → Дні» або «Групи», «Вид змагань» |
| Естафета «за номером етапу»: номер етапу без придатної дистанції | помилка | «Учасники», «Група» |
| Учасник у команді без етапу | помилка | «Змагання → Естафета → Команди» |
| Неповна команда (вона поза конкурсом, доки не заповнено всі етапи) | попередження | «Команди» |
| Команда без номера | попередження | «Команди» |
| «Варіанти за номерами»: варіант призначено в іншій групі; номер учасника розсіювання без варіанта | попередження | «Варіанти за номерами» |

Групи, у яких на цей день немає ні учасників, ні команд, не перевіряються: вони нічого не зіпсують.

## Час старту {#start-time}

Без часу старту учасник без відмітки на станції «Старт» отримує DNS. Програма перевіряє це так:

- **Ні в кого в дні немає часу старту** — один рядок на весь день: жеребкування ще не проведено, або старт
  фіксує станція «Старт». Якщо у вас саме так задумано, це попередження можна не зважати.
- **Частину дня вже розжеребовано** — рядок на кожну групу, де часу немає ні в кого, і рядок на кожного учасника без
  часу в групі, де решту розжеребовано (наприклад, пізня заявка).
- В естафеті перевіряється лише перший етап: його старт — час учасника або масовий старт групи. Наступні етапи
  стартують з передачі.

## Що тут не перевіряється

- **Вимкнені КП** («Проблемні КП») — це рішення судді, а не помилка даних.
- **Зчитки на фініші**, наприклад чіп, якого немає в жодного учасника. Це вже день змагань: такі зчитки червоні в
  журналі «Фініш → Зчитка на фініші».
- Оплата і «Мандатку пройдено».
