# Протокол по сумі днів

Протокол по сумі днів — загальний залік багатоденних змагань: для кожного учасника програма складає його
результати за вибрані дні, розставляє місця в групі і формує документ Word. Відкривається через «Результати →
Протокол по сумі днів».

![Протокол по сумі днів](../shots/summary-protocol.png){ .shot }

На знімку — «Параметри заліку»: режим, дні, пріоритетний день, групи й вигляд аркуша. Нижче на сторінці — макет
документа: колонки учасника, потім по блоку на кожен день (місце, час, очки) і «Сума» в кінці.

Спробувати можна на демо [Кубок міста](../demo/demo-kubok.opyx) з двома днями: двічі клацніть завантажений файл і
натисніть «Ок» (запасний варіант — «Файл → Імпорт змагань…»). Правил очок у ньому не призначено, тож оберіть «За
сумою часу» або спершу призначте правило групам.

## Як рахувати: за очками чи за часом {#mode}

У «Як рахувати суму:» оберіть:

- **«За очками»** — сума «Очок» за дні. Очки нараховуються за місце в кожному дні за правилом очок групи, тож
  спершу призначте правила (див. [Очки і розряди](points-ranks.md#assign)). Без правила в учасників немає очок,
  і залік буде порожній.
- **«За сумою часу»** — сума результатів (часу) за дні. Блок дня тоді має лише колонки «М» і «Час».

| | «За очками» | «За сумою часу» |
|---|---|---|
| Що сумується | «Очки» кожного дня | час кожного дня, лише зі статусом OK |
| Хто отримує місце | усі, хто має очки хоч за один день; з опцією «У заліку тільки учасники, які мають результат у всі дні» — лише ті, хто має очки за кожен вибраний день | лише ті, хто має результат OK у **кожен** вибраний день і жодного дня не біг поза конкурсом |
| Порядок | більша сума вище; за рівної суми — у кого більше днів з очками, далі — більше очок у пріоритетний день | менша сума вище; за рівної суми — кращий час у пріоритетний день |
| Без місця | у кінці групи за алфавітом, колонка «Місце» порожня | так само |

- **Пріоритетний день.** «Пріоритетний день (при рівності):» — день, результат якого вирішує при однаковій
  сумі. «Без пріоритету» — однакова сума дає однакове місце (у режимі «За очками» тоді не враховується й кількість
  днів).
- **Пропущений день** у клітинках дня показано прочерком.
- **Учасник змінив групу** між днями — він має окремий рядок у кожній групі, з днями, які біг у ній.
- **Естафета.** У режимі «За очками» день естафети рахується: кожен учасник команди отримує очки команди. У
  режимі «За сумою часу» дні естафети пропускаються — час етапу не є особистим результатом.

!!! note "Поза конкурсом в окремий день"
    У день, коли учасник біг поза конкурсом, у блоці дня в нього «П/К» і немає очок — у режимі «За очками» цей
    день йому не зараховується. У режимі «За сумою часу» поза конкурсом стає вся його сума: загальний час
    показано, але місця немає.

## Налаштувати залік {#settings}

У блоці «Параметри заліку»:

1. «Як рахувати суму:» — «За очками» або «За сумою часу».
2. «У заліку тільки учасники, які мають результат у всі дні» — є лише в режимі «За очками».
3. «Дні для заліку» — позначте дні, які входять у суму; стрілками змініть їхній порядок у таблиці.
4. «Пріоритетний день (при рівності):».
5. «Групи» — які групи потрапляють у протокол. «Усі», «Жодної» або «За замовчуванням»: тоді в протоколі лише
   групи, де хтось уже має ненульовий результат, і нова група з'явиться сама, щойно в неї будуть результати.
6. Прапорці вигляду аркуша — як у протоколі результатів: альбомна орієнтація, межі клітинок, колонтитули.

У макеті:

- клацніть текст шапки, щоб його змінити (порожні поля беруться з даних змагання);
- позначте в «Колонки», які колонки учасника показувати («Місце», «Номер», «Прізвище, ім'я», «ДН», «Регіон»,
  «Клуб», «ДЮСШ», «Тренер», «Кваліфікація»), і перетягуйте їхні заголовки, щоб змінити порядок. Блоки днів і
  «Сума» завжди в кінці.

Налаштування зберігаються автоматично для цих змагань. «Зберегти для наступних змагань» робить їх шаблоном за
замовчуванням.

## Сформувати і надрукувати {#export}

- «Сформувати протокол» — зберегти `.docx` (після збереження він відкриється у Word). Наприкінці документа —
  підписи суддів зі сторінки «Інформація».
- «Друк переможців» — призери загального заліку (перші три місця кожної групи) на чековому принтері, як і для
  одного дня (див. [Друк переможців](../race-day/results.md#winners)). Друкуються лише групи, вибрані в «Групи».

!!! tip "Спершу перевірте дні"
    Протокол по сумі днів бере ті самі результати, що й протоколи окремих днів. Якщо в якомусь дні результат
    неправильний, виправте його в тому дні (зчитка, статус) — сума перерахується сама. Пов'язане: [Багатоденні
    змагання](../guides/multi-day.md).
