# OrientPyx — API плагінів

Посібник для авторів плагінів тепер живе на сайті документації:
**https://vadymkolesnyk.github.io/OrientPyx/plugins/** — коли потрібен плагін, перший плагін крок за кроком,
повний довідник API, розбір стандартних плагінів, поширення й версії, налагодження.

Джерело цих сторінок — `website/content/plugins/` (Markdown, MkDocs). Довідник API (`api.md`) має згадувати
кожен публічний тип збірки `OrientPyx.Plugins.Sdk` — це перевіряє тест `tests/OrientPyx.Tests/Core/PluginDocsTests.cs`.
