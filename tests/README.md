# Тести OrientPyx

Окреме рішення `tests/OrientPyx.Tests.sln` (як і `plugins/`), щоб `OrientPyx.sln` лишався без тестових
проєктів. Один проєкт `OrientPyx.Tests` (xunit) перевіряє застосунок двома способами:

- **Ядро** (`Core/`) — ті самі DI-реєстрації, що й у застосунку (`AddOrientPyxLocalization/BusinessLogic/DataAccess`),
  над тимчасовим коренем даних у `%TEMP%\OrientPyx.Tests\<час>-<pid>`.
- **UI** (`Ui/`) — справжній `App` + `MainWindow` на headless-платформі Avalonia з Skia-рендерингом
  (`Support/HeadlessApp.cs`): тести керують view-моделями, чекають на зникнення busy-оверлею й зберігають знімки
  вікна до `tests/TestResults/<час>/*.png`.

## Запуск

```bash
dotnet test tests/OrientPyx.Tests.sln
```

Перший запуск збирає і стандартні плагіни (`artifacts/plugins`), бо тести перевіряють їх завантаження.

## Що перевіряється

| Тест | Що саме |
|------|---------|
| `ResultsGoldenTests` | обчислені результати кожного змагання = затверджений знімок (`Golden/autotest.results.json` для синтетичного; `tests/fixtures/<id>.results.json` для реальних) |
| `OutputsTests` | для кожного дня: протоколи результатів/стартові/підсумковий/відомість у .docx, спліти й монітор у HTML, переможці, онлайн-знімок, жеребкування, порядок старту, швидке зняття, спліти та чек кожної зчитки |
| `DisciplineSweepTests` | день 1 перемикається через усі стратегії (вбудовані + плагінні) і всі виходи будуються |
| `PluginCatalogTests` | синхронізація стандартних плагінів у `<data root>/plugins`, повторна синхронізація, вимкнені за замовчуванням, живе вмикання |
| `ArchiveRoundTripTests` | експорт `.opyx` → імпорт → результати ідентичні |
| `HeadlessUiTests` | вибір змагання, відкриття кожної сторінки з меню, учасники, вмикання плагіна зі сторінки «Плагіни», налаштування та зміна мови, «Про програму» |

## Дані

- Синтетичне змагання `autotest` будується кодом (`Support/SyntheticCompetition.cs`): 2 дні, 2 групи, 4 КП,
  6 учасників, зчитки дня 1 (OK, однакові часи, пропущений КП, ще на дистанції). Його знімок результатів
  закомічено в `Golden/`; якщо зміна результатів навмисна — перезапишіть файл із `tests/TestResults/<час>/autotest.actual.json`.
- Реальні змагання кладуть у `tests/fixtures/*.opyx` (git-ігнор, див. `fixtures/README.md`).

Знімок результатів має той самий формат, що й «Файл → (Debug) Знімок результатів…», тож два файли можна
порівняти `scripts/diff-results.ps1`.
